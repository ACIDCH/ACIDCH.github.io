## 发布门禁及边界

推送后必须通过 CI 的完整质量检查、桌面 / 手机路线渲染验证，才允许 Pages 部署；随后核对生产版本 SHA 和线上页面。CI 和生产复测结果以对应 GitHub Actions 发布记录为准，本文件不提前宣称部署成功。

已有大于 500 kB 的构建分块提示仍在。函数级性能测试不代表真实设备的首屏、INP 或网络表现；未为消除此提示而改动求解器或移除功能。搜索全文索引仍内嵌在 HTML，本轮优化的是重复查询计算，不声称降低其传输体积。

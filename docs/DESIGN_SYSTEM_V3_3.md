# V3.3 Design System

The interface follows an original **Southern Alpine Minimal** direction. Its
warm off-white, charcoal, lake blue, moss green and warm rock accent tokens are
derived from the supplied Queenstown, Mount Cook and Wānaka photographs.

## Foundations

- Layout widths: `--container-wide` (82rem), `--container-project` (72rem), and
  `--container-content` (70ch).
- Spacing: the shared 4–96px token scale in `src/styles/tokens.css`; components
  do not introduce arbitrary outer gutters.
- Type: local system sans-serif stacks only. English and Chinese share role
  sizes; Chinese copy avoids forced uppercase and excessive letter spacing.
- Images: home hero 16:9 desktop / portrait mobile, About hero 2:1, project
  covers 3:2, profile portrait 1:1 circular.
- Controls: 44px minimum icon controls, visible focus rings, restrained borders,
  and consistent hover/active/disabled states.
- Motion: 140–320ms state and hierarchy transitions. Reduced-motion removes
  parallax, reveal and page-transition movement.
- Surfaces: opaque content surfaces are standard. Blur is limited to the sticky
  header; dialogs use solid surfaces and strong backdrops.

## Asset policy

Processed WebP files are generated by `scripts/process-reference-assets.py`.
The script writes no EXIF, XMP, ICC or GPS payload. User-supplied originals stay
inside the ignored V3.3 source package and never enter `public/` or `dist/`.

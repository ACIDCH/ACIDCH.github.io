## 已确认的问题

1. 双语文件配对齐全，但中文正文、摘要和交互组件仍存在英文说明。
2. 五个中文项目使用专用组件，英文项目使用通用 Markdown 布局。仅检查 Markdown 无法覆盖中文实际页面；本批不改变渲染器或删减功能。
3. 最终双语审计读取保存的 manifest，没有重新检查当前源文件，可能错过后续改动。
4. Lint 扫描了 git 忽略的 tmp 浏览器缓存及第三方扩展代码，产生与正式源码无关的错误。
5. 首页窄屏实测有中文标题断词；需要在三个样板中重新验证字体与容器宽度。现有多个背景和润色样式文件的覆盖关系也需整理。

# Security and privacy

This repository is intended to be public.

Do not commit secrets, API keys, passwords, private contact details, reference
contacts, confidential employer data, restricted university material, raw
graded assignments, teacher-provided solutions, or other students' work.

Local environment files are ignored by Git. If configuration values are needed
later, document safe placeholders in `.env.example` and keep real values out of
the repository.

Only public, self-created, simulated, licensed, or properly anonymised data may
be used in demonstrations.

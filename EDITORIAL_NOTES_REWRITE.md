# Learning Notes editorial rewrite

This branch rewrites the public Chinese Learning Notes copy while keeping the existing information architecture, datasets, formulas, code examples and interactive components intact.

Scope:

- 27 published Chinese Learning Notes.
- SQL 01–09.
- Supply chain and optimisation DM 01–10.
- Regression REG 01–07.
- Statistics handbook.
- Series-folder module titles and summaries.
- Production verifiers and editorial tests that lock the new concise titles.

Editorial rules:

- Keep titles short enough to scan naturally on cards.
- Put technical detail in the article, not in keyword-heavy title tails.
- Start from the actual question or data situation before introducing terminology.
- Preserve formulas, canonical numeric examples, runnable code and interactive learning blocks.
- Avoid catalogue-style summary language and repeated template transitions.
- Keep public prose free of first-person narration and private/course-facing labels.

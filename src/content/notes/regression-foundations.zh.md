## 回归首先是一种问题表达

简单线性回归最常见的误解，是把它看成“画一条最接近散点的直线”。真正重要的起点是先明确业务问题：**一个连续结果变量 Y，是否会随着一个解释变量 X 的变化呈现可解释的平均趋势？**

例如，配送距离增加是否伴随配送时长上升；服务请求复杂度提高是否伴随处理时间增加；广告投入变化是否与订单量变化存在近似线性关系。这里的“线性”不是要求每个观察值都恰好落在一条直线上，而是要求条件均值可以用一条直线近似表达。

简单线性回归写作：

\[
Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i
\]

其中，\(\beta_0\) 是截距，\(\beta_1\) 是斜率，\(\varepsilon_i\) 表示模型没有解释的那部分变化。模型真正描述的是：

\[
E(Y\mid X=x)=\beta_0+\beta_1x
\]

因此，回归线不是“每条记录的命运”，而是给定 X 后 Y 的平均结构。

## 建模前先看散点图

回归前的散点图不是装饰。它至少需要检查四件事：方向、函数形式、离散程度和异常结构。

| 图形信号 | 可能含义 | 建模动作 |
| --- | --- | --- |
| 点云大致向右上 | 正向关系 | 可以继续评估线性趋势 |
| 点云大致向右下 | 负向关系 | 斜率可能为负 |
| 中间平缓、两端弯曲 | 非线性 | 考虑变换或多项式项 |
| 右侧越来越分散 | 异方差 | 检查方差结构与区间可靠性 |
| 单个点远离主体 | 潜在异常/影响点 | 不应直接删除，先诊断 |

散点图还可以暴露量纲问题。例如 X 取值范围极窄时，即使计算得到很大的斜率，也可能只是单位尺度造成的视觉夸张。

## 最小二乘在最小化什么

观察值与拟合直线之间的竖直差称为残差：

\[
e_i=y_i-\hat y_i
\]

普通最小二乘（OLS）选择 \(\hat\beta_0\) 与 \(\hat\beta_1\)，使残差平方和最小：

\[
SSE=\sum_{i=1}^{n}(y_i-\hat y_i)^2
\]

平方的作用有两层：正负误差不会互相抵消，同时大误差会被更重地惩罚。简单线性回归的斜率可以写成：

\[
\hat\beta_1=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}
\]

截距为：

\[
\hat\beta_0=\bar y-\hat\beta_1\bar x
\]

这也解释了一个重要性质：带截距的 OLS 回归线必然经过样本均值点 \((\bar x,\bar y)\)。

## 斜率怎么解释才不越界

假设得到：

\[
\widehat{DeliveryHours}=1.8+0.065\times DistanceKm
\]

斜率 0.065 表示：在当前样本所覆盖的范围内，配送距离每增加 1 km，预测的平均配送时长增加约 0.065 小时。它表达的是**样本中观察到的条件关联**，并不自动意味着“增加距离会因果地造成 0.065 小时延迟”。

截距 1.8 表示 X=0 时模型的预测值。如果数据中从未出现接近 0 km 的记录，那么截距更多是计算上用于确定直线位置的参数，不宜强行赋予业务解释。

另一个常见错误是外推。如果历史距离主要在 5–80 km，直接用同一条直线预测 400 km 路线，已经超出样本支持范围。线性模型不会主动提醒外推风险，因此解释必须附带适用区间。

## R²回答什么，不回答什么

总平方和描述 Y 的总体波动：

\[
SST=\sum(y_i-\bar y)^2
\]

回归解释部分与残差部分满足：

\[
SST=SSR+SSE
\]

于是：

\[
R^2=1-\frac{SSE}{SST}
\]

R²越高，表示样本中的 Y 变异有更大比例被当前线性模型解释。但 R² 高并不代表模型具有因果解释，也不代表残差假设成立，更不代表样本外预测一定好。对于强时间趋势数据、存在数据泄露的模型或高度复杂的模型，R² 同样可能很高。

## 斜率精度取决于噪声，也取决于 X 的覆盖范围

斜率标准误的结构可以直观写成：

\[
SE(\hat\beta_1)\propto\frac{\sigma}{\sqrt{\sum(x_i-\bar x)^2}}
\]

这说明估计精度并不只由样本量决定。若 Y 在回归线周围的噪声 \(\sigma\) 很大，斜率会更不稳定；另一方面，如果所有 X 都挤在一个很窄的区间，即使记录很多，也很难精确判断趋势。相反，在不改变目标总体的前提下，X 覆盖更充分通常能提供更多斜率信息。

例如两份配送数据都包含 200 条订单。第一份距离集中在 35–45 km，第二份覆盖 5–90 km。即使两者误差水平相近，第二份数据通常更有能力区分“距离效应到底有多大”。这也是为什么只比较样本数会遗漏设计信息。

但扩大 X 范围不能通过混入不属于同一总体的记录来实现。若把城市短途订单和跨区域干线运输直接放进一条回归线，得到的“更宽范围”可能只是把两个不同流程硬拼在一起。精度提升必须建立在可比业务机制上。

从决策角度看，这一结果还有一个直接含义：若未来预测主要发生在历史样本边缘，新增数据最有价值的位置往往不是继续采集大量中间区域记录，而是补足目标使用范围内较稀疏的区域。数据收集设计和回归精度因此是同一个问题的两面。

## 斜率显著性：检验的对象是总体参数

常见假设为：

\[
H_0:\beta_1=0,\qquad H_1:\beta_1\neq0
\]

检验统计量：

\[
t=\frac{\hat\beta_1-0}{SE(\hat\beta_1)}
\]

p 值回答的是：**如果总体斜率确实为 0，那么得到当前这么极端或更极端样本结果的概率有多大。** p 值不是“原假设为真的概率”，也不是业务价值大小。

斜率的置信区间比单独报 p 值更有信息，因为它同时给出方向和估计精度：

\[
\hat\beta_1\pm t_{\alpha/2,n-2}SE(\hat\beta_1)
\]

如果区间非常窄但效果很小，统计上可能显著，业务上仍未必重要；如果区间很宽，则说明样本对效应大小的约束还不够强。

## 均值置信区间与单条预测区间不是同一件事

给定新的 \(x_0\)，可以估计平均结果：

\[
E(Y\mid X=x_0)
\]

也可以预测一条新的个体记录：

\[
Y_{new}\mid X=x_0
\]

这两个问题的不确定性不同。均值置信区间只需要考虑回归线位置的不确定性；预测区间还要加上个体随机误差，所以通常更宽。

在运营场景中，这个区别很实用：预测“某类订单的平均处理时间”适合均值置信区间；承诺“下一张订单大概会在多久内完成”更接近预测区间。

## 在 R 中建立最小可复查流程

```r
model <- lm(delivery_hours ~ distance_km, data = delivery)
summary(model)
confint(model)

new_route <- data.frame(distance_km = c(25, 60))
predict(model, newdata = new_route, interval = "confidence")
predict(model, newdata = new_route, interval = "prediction")
```

建模代码应当和数据粒度一起阅读。`delivery` 中每一行究竟是一张订单、一次路线还是某日汇总，会直接改变系数解释。模型语法正确并不等于分析口径正确。

## 噪声与极端点为何会改变直线

OLS 使用平方误差，因此离拟合线很远的点会贡献很大的损失。如果这个点同时位于 X 的边缘，它还可能具有高杠杆，从而明显改变斜率。互动图中的“最后一条记录偏移”可以直接观察这种变化。

这并不意味着极端点应该自动删除。正确顺序应是：先确认数据是否录入错误，再判断它是否属于目标总体，然后评估该点对模型系数、残差和预测的影响。如果它是真实但罕见的业务状态，删除它可能反而让模型失去最重要的风险信息。

## 一条合格的简单回归证据链

简单线性回归至少应形成以下证据链：业务问题明确 → 观察单位明确 → 散点图合理 → 回归系数估计 → 残差与模型条件检查 → 效应大小和区间解释 → 样本范围说明 → 预测对象和区间类型匹配。

只有完成这条链，`lm()` 的输出才从“统计结果”变成可用于决策沟通的分析结果。

## 常见错误清单

- 把相关或回归斜率直接写成因果关系。
- 只看 R²，不看散点图与残差图。
- 把 p<0.05 等同于“业务效果很大”。
- 用置信区间替代个体预测区间。
- 在样本范围之外大量外推。
- 看到异常点就删除，而不检查来源和影响。
- 忽略观察单位，导致系数解释错位。

## 回归到底在回答什么问题

简单线性回归最适合处理这样一类问题：一个连续结果，会不会随着另一个变量的变化而出现比较稳定的平均趋势？

比如配送距离变长以后，配送时间通常会不会增加；广告投入提高以后，订单量是否大致跟着上升；服务请求更复杂时，处理时间会不会普遍变长。这里关心的不是每一条记录都能不能落在同一条直线上，而是整体上有没有一条值得解释的平均关系。

模型写成：

\[
Y_i=\beta_0+\beta_1X_i+\varepsilon_i
\]

其中 \(Y_i\) 是结果，\(X_i\) 是解释变量，\(\beta_0\) 是截距，\(\beta_1\) 是斜率，\(\varepsilon_i\) 则装下了模型没有解释掉的那部分差异。

更准确地说，回归线描述的是：

\[
E(Y\mid X=x)=\beta_0+\beta_1x
\]

也就是说，它讲的是给定 X 后 Y 的平均水平，而不是给某一条记录下结论。

## 先看散点图，再决定要不要回归

回归前最值得花时间看的往往不是模型输出，而是一张散点图。

如果点云大致沿一条直线分布，线性模型通常有一个合理起点；如果明显弯曲，或者不同 X 区间的波动程度差很多，那么直接塞进一条直线就可能过于勉强。

还要留意几个很实际的现象：

- 是否有一两个点远离大多数数据；
- X 的取值是不是只集中在很窄的范围；
- 点云有没有明显分组；
- 某些区间是不是几乎没有数据。

这些信息不会自动出现在一个 R² 里，却会直接影响后面对系数和预测的解释。

## 最小二乘怎样找到那条线

一组数据上可以画很多条直线。最小二乘法选择的是让残差平方和最小的那一条。

第 i 个观察值的残差是：

\[
e_i=y_i-\hat y_i
\]

所有残差平方加起来：

\[
SSE=\sum_{i=1}^{n}(y_i-\hat y_i)^2
\]

OLS，也就是 Ordinary Least Squares，寻找让 SSE 最小的 \(\hat\beta_0\) 和 \(\hat\beta_1\)。平方的作用很直观：正负残差不会互相抵消，而且偏得特别远的点会被更重地惩罚。

这也是为什么极端点值得特别注意。一个离群观察对平方损失的贡献可能非常大，足以把整条线拉向自己。

## 斜率是最需要解释清楚的系数

假设模型估计为：

\[
\widehat{delivery\_time}=18.4+1.7\times distance
\]

斜率 1.7 的自然解释是：在当前数据范围和模型设定下，配送距离每增加 1 个单位，平均配送时间大约增加 1.7 个单位。

这里有三个词不能省：**平均、当前数据范围、模型设定**。

斜率并不自动意味着因果。即使距离和配送时间有明显关系，也可能同时受到交通、路线类型、订单规模等变量影响。单变量回归能描述关联，但不能仅凭一条回归线证明“X 导致 Y”。

## 截距有时有意义，有时只是数学上的落点

截距 \(\beta_0\) 表示当 X=0 时 Y 的条件均值。

如果 X=0 在业务上有意义，而且样本确实覆盖了 0 附近，那么截距可以直接解释。如果数据中的 X 全部落在 50 到 100 之间，模型却给出了 X=0 时的预测，这个数字更多只是直线的数学延伸。

所以看到截距时，不必强行给它编一个业务故事。先看 0 是否处在合理的数据范围里。

## R² 只回答“解释了多少波动”

R² 常被用来描述模型拟合程度：

\[
R^2=1-\frac{SSE}{SST}
\]

其中 SSE 是模型没有解释的平方和，SST 是结果变量相对自身均值的总平方和。

如果 R²=0.68，可以说当前线性模型解释了样本中约 68% 的 Y 变异。但它不能单独回答下面这些问题：

- 关系是不是因果；
- 模型形式是不是正确；
- 残差有没有明显结构；
- 新数据上的预测是不是可靠；
- 某个系数在业务上是不是重要。

高 R² 也可能来自很强的时间趋势或少数极端点，低 R² 也不代表模型完全没用。要不要接受一个模型，不能只看这一列数字。

## 系数估计还需要看不确定性

样本中的斜率 \(\hat\beta_1\) 只是总体斜率的估计。换一批样本，结果通常会有变化。

因此输出里还会看到标准误、t 统计量、p 值和置信区间。它们不是四件互不相干的东西，而是在描述同一件事：**当前样本对系数位置掌握得有多确定。**

常见的检验是：

\[
H_0:\beta_1=0
\]

如果数据与零斜率很难相容，p 值会变小。但“统计显著”不等于“业务影响大”。样本很多时，一个非常小的斜率也可能显著；反过来，一个实际影响不小的关系，在样本太少时也可能没有足够精度。

更完整的阅读方式是把系数大小、置信区间和业务尺度放在一起看。

## 置信区间和预测区间不是一回事

假设要在某个 \(X=x_0\) 处估计 Y。

如果问题是“这一类对象的平均结果大概是多少”，关注的是平均响应的置信区间。它描述的是：

\[
E(Y\mid X=x_0)
\]

如果问题是“下一条具体记录大概会落在哪里”，需要的是预测区间。单个观察值除了受到回归线估计误差影响，还带着自己的随机误差，所以预测区间通常更宽。

这两个区间经常被画在同一张图上，但业务含义完全不同。预测一群客户的平均需求和预测下一位客户的实际需求，不能用同一个区间回答。

## 噪声和极端点会怎样改变模型

当误差波动变大时，散点会离回归线更远。斜率点估计可能仍然接近原值，但标准误通常会上升，置信区间也会变宽。

极端点的影响则更复杂。一个 X 值很极端的观察可能拥有很高的 leverage；如果它同时在 Y 方向上也偏离趋势，就可能明显改变斜率。

因此，看到一条“很漂亮”的回归线之后，仍然要检查数据是不是被少数记录牵着走。回归诊断并不是模型做完后的装饰，而是判断这条线能不能相信的一部分。

## 用 R 拟合和读取模型

基础模型可以直接用 `lm()`：

```r
model <- lm(delivery_time ~ distance, data = delivery_df)
summary(model)
```

常见输出包括：

```text
Coefficients
Residual standard error
Multiple R-squared
Adjusted R-squared
F-statistic
```

如果只想拿系数：

```r
coef(model)
```

预测新的 X：

```r
new_case <- data.frame(distance = 12)
predict(model, newdata = new_case)
```

平均响应的置信区间：

```r
predict(model, newdata = new_case, interval = "confidence")
```

单个新观察的预测区间：

```r
predict(model, newdata = new_case, interval = "prediction")
```

代码本身很短，真正需要判断的是：模型是否适合当前问题，系数是否能按当前数据范围解释，以及区间是否对应真正要回答的问题。

## 一份更可靠的阅读顺序

面对一份简单线性回归结果，可以按下面的顺序看：

1. 先看散点图，确认线性关系是否勉强合理；
2. 看斜率方向和大小，先解释实际含义；
3. 再看标准误、置信区间和 p 值，判断估计精度；
4. 用 R²了解模型解释了多少样本波动；
5. 区分平均响应区间和单个观察的预测区间；
6. 最后检查残差和影响点，确认结论没有被明显结构破坏。

简单线性回归的价值不在于“画出一条线”，而在于把一个平均关系、它的不确定性和它的适用边界同时说清楚。下一篇会专门处理最后这一步：怎样从残差里判断模型哪里出了问题。

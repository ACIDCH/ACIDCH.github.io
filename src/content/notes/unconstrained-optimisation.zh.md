## 无约束不等于没有现实边界

“Unconstrained optimisation”表示数学表达中暂时没有显式写出的约束条件，而不是现实世界真的没有限制。

它特别适合先回答一类基础问题：

> 当一个决策变量变化时，目标函数本身怎样变化，最佳点为什么出现在那里？

例如容量决策可能同时带来两种力量：

```text
更多容量
→ 增加可服务业务量与价值

更多容量
→ 增加拥堵、维护、预留或低利用率成本
```

如果第二种效应随着容量扩大越来越强，净价值可能先上升、达到峰值，再下降。

## 单变量优化首先看函数形状

考虑一个合成容量模型：

```text
V(x) = 96x - 0.08x² - 18000
```

其中：

```text
x      = 容量决策
96x    = 容量带来的线性价值
0.08x² = 随规模加速增加的拥堵或复杂度成本
18000  = 与 x 无关的基准成本
```

这个函数是开口向下的抛物线，因此存在一个内部最大值。

一阶导数：

```text
V'(x) = 96 - 0.16x
```

在内部最优点：

```text
V'(x*) = 0
```

所以：

```text
96 - 0.16x* = 0
x* = 600
```

## 边际变化比“函数值最大”更有解释力

一阶导数可以理解为：

> 决策变量再增加一个很小单位时，目标大约改变多少？

当 `x < 600`：

```text
V'(x) > 0
```

继续增加容量仍会提高净价值。

当 `x > 600`：

```text
V'(x) < 0
```

额外容量造成的新增成本已经超过新增价值。

当 `x = 600`：

```text
V'(x) = 0
```

局部边际改善消失。

这比单纯记忆“导数等于零”更重要，因为它解释了最优点为什么是转折位置。

## 二阶导数告诉这个驻点是什么

仅有：

```text
f'(x) = 0
```

不能保证得到最大值。

二阶导数用于观察曲率：

```text
f''(x) < 0 → 局部最大值倾向
f''(x) > 0 → 局部最小值倾向
```

当前模型：

```text
V''(x) = -0.16
```

始终小于 0，因此函数整体是 concave，`x = 600` 也是全局最大点。

## 局部最优与全局最优必须区分

复杂函数可能有多个峰和谷。

```text
Local optimum
→ 在附近区域最好

Global optimum
→ 在整个允许搜索空间中最好
```

对于单峰的凹函数，两者容易一致；对于非凸模型、离散选择或复杂非线性函数，局部最优并不能自动代表全局最优。

这也是为什么求解方法不能脱离模型结构讨论。

## 没有内部驻点时，最优可能出现在业务边界

即使章节主题是“无约束”，实际实现通常仍会给决策设置一个合理搜索区间。

例如净价值函数如果在整个可考察区间内一直上升：

```text
V'(x) > 0 for all x in [0, 700]
```

那么区间内最佳点会出现在：

```text
x = 700
```

这不是因为 `V'(700)=0`，而是因为更大的 x 已经不在当前决策范围内。

类似地，如果函数始终下降，最佳点可能在左边界。

因此完整检查顺序不能只写：

```text
求导 → 令导数为 0 → 得答案
```

而应是：

```text
1. 检查函数定义域与业务可接受范围
2. 找内部 stationary points
3. 判断二阶形状
4. 比较必要的边界值
5. 判断是否存在多个 local optima
```

这个思路为下一章显式约束优化提供了自然过渡。

## 固定项不会改变内部最优位置

当前函数中的：

```text
-18000
```

只会把整条曲线整体向下移动。

因为：

```text
d(-18000)/dx = 0
```

所以它不会改变 `x* = 600`。

但固定项会改变目标值是否为正、方案是否值得进入现实决策。

因此需要区分：

```text
影响最优位置的项
vs
影响整体经济价值但不改变最优位置的项
```

## 数学最优点附近通常存在“近最优区”

最优点不是一堵墙。

在当前函数中，575、600、625 的净价值差距远小于从 450 或 750 偏离时的差距。

这说明一个很有管理价值的现象：

> 当目标曲线在最优点附近比较平缓时，企业可能拥有一个可接受的 near-optimal region。

现实实施中，标准设备规格、整班排程、车辆整车数、供应商合同档位等经常迫使决策从数学连续最优点移动到有限候选值。

此时应计算：

```text
Opportunity loss = V(x*) - V(x_candidate)
```

再把这个损失和运营便利、实施风险、采购折扣或标准化收益进行比较。

## 可以把 near-optimal region 定义成可解释的决策带

与其只说“575 也差不多”，更专业的做法是先定义一个可接受损失阈值。

例如允许目标值相对最优最多损失 100：

```text
V(x*) - V(x) ≤ 100
```

所有满足这一条件的 x 可以组成一个 decision band。

这种做法特别适合：

```text
设备规格选择
标准车辆数
整班排程
仓容档位
供应商合同等级
```

因为现实常常不是从连续数轴任取一个值，而是在若干标准方案之间选择。

决策带的价值在于把“几乎一样好”从主观感觉变成明确阈值。阈值本身仍需要业务依据，例如实施复杂度、预算容忍度或服务风险。

## “最优 600”与“必须执行 600”不是同一句话

优化输出应回答：

```text
600 为什么最好？
575 损失多少？
625 损失多少？
偏离多少以后损失开始快速扩大？
```

如果 575 只比理论最优低很少，但恰好匹配现有班次与设备规格，那么 575 可能仍是合理的管理选择。

这种分析保留了模型的价值：模型提供**量化基准**，而不是把业务判断简化成机械执行。

## 导数法、网格搜索与 Solver 各自回答什么

对于当前简单二次函数，解析求导是最透明的方法：

```text
V'(x)=0
```

可以直接得到 600。

但实际模型未必总有容易处理的解析形式。

### 网格搜索

可以在合理区间逐点计算：

```text
x = 450, 455, 460, ... , 750
```

然后比较 `V(x)`。

优点是直观、容易画图，也适合验证解析答案。

缺点是精度依赖步长，而且变量一多，组合数量会迅速膨胀。

### 数值 Solver

Solver 适合更复杂的连续非线性目标或多变量模型。

但 Solver 输出不能替代函数理解。至少仍应检查：

```text
起始值
收敛状态
解是否落在合理区间
附近扰动是否真的降低目标
不同起点是否得到同一结果
```

因此“解析法、搜索法、Solver”不是互相排斥的三种答案，而可以构成互相验证的三层方法。

## 离散执行值需要重新比较，而不是直接四舍五入

如果理论最优：

```text
x* = 603.7
```

而现实只能采购：

```text
575, 600, 625
```

不能仅因为 600 离 603.7 最近就自动选择 600。

应该分别计算：

```text
V(575)
V(600)
V(625)
```

因为目标函数可能不对称，距离最近不一定意味着目标损失最小。

同样，整数决策也不应简单使用：

```text
round(x*)
```

如果相邻整数会触发不同固定费用或商业规则，那么原问题实际上已经从连续无约束优化转向整数/MILP 模型。

这也是连续分析与后续离散优化之间的重要边界。

## 多变量无约束优化把斜率扩展成梯度

如果决策变量不止一个：

```text
f(x, y)
```

需要同时考虑：

```text
∂f/∂x
∂f/∂y
```

内部驻点通常满足：

```text
∇f = 0
```

即：

```text
∂f/∂x = 0
∂f/∂y = 0
```

但和单变量一样，“梯度为零”只是候选条件，还要检查函数形状和二阶信息。

供应链中的两个决策变量可能代表：

```text
永久员工数量 + 临时员工数量
自有仓储容量 + 外包容量
基础库存 + 加急补货能力
```

多个变量的价值在于允许模型表达替代关系：增加一种资源可能降低另一种资源的需要。

## 多变量中的二阶信息由 Hessian 承担

单变量用：

```text
f''(x)
```

判断曲率。

多变量模型则需要考虑由二阶偏导数组成的 Hessian matrix。

对于最大化问题，如果目标在整个区域内是严格 concave，那么找到满足：

```text
∇f = 0
```

的内部点通常可以更有把握地解释为全局最大点。

如果 Hessian 显示不同方向存在不同曲率，驻点可能是 saddle point，而不是最大或最小。

业务上可以把 saddle point 理解为：沿一个决策方向移动会改善目标，沿另一个方向移动却会恶化目标，所以“所有一阶偏导暂时为零”仍不足以说明方案最好。

## 决策变量之间可以存在交互

例如：

```text
f(x,y) = value(x,y) - cost(x,y)
```

如果存在 `xy` 项，说明一个决策的边际效果依赖另一个决策的水平。

这类模型不能简单把 x 和 y 分开各自优化，因为：

```text
best x given y=20
```

可能和：

```text
best x given y=50
```

完全不同。

因此多变量优化需要把变量看成一个联合决策向量，而不是多个互不相关的单变量问题。

## Solver 为什么仍然需要起点和范围意识

即使没有显式约束，数值求解也不等于“无限世界自动搜索”。

非线性模型中需要关注：

- 起始值可能影响收敛路径；
- 函数可能有多个局部最优；
- 极端区域可能没有经济意义；
- 数值尺度过大或过小可能影响稳定性；
- 实际业务变量常常仍有自然边界。

所以模型检查应同时看公式、曲线和结果，而不是只看求解器最后一格。

## 敏感性思维从无约束模型就可以开始

即使还没有“Shadow Price”，也可以问：

```text
线性价值 96 改变时，最优容量怎样移动？
拥堵系数 0.08 增大时，最优容量怎样移动？
固定成本变化是否影响最优位置？
```

从公式：

```text
x* = a / (2b)
```

可以直接看出：

```text
a 增大 → 最优容量提高
b 增大 → 最优容量降低
固定项 c → 不改变内部最优位置
```

这种参数—决策关系是后续敏感性分析的基础。

## 用参数表观察最优点如何移动

如果函数写成一般形式：

```text
V(x) = ax - bx² - c
```

则内部最大点：

```text
x* = a / (2b)
```

可以系统观察：

```text
a = 80, 96, 112
b = 0.06, 0.08, 0.10
```

每个组合都重新计算 `x*` 和最优目标值。

这种参数表能区分两种问题：

```text
Decision sensitivity
→ 最优 x 移动多少？

Objective sensitivity
→ 最优价值变化多少？
```

某个参数可能让目标值变化很大，却几乎不改变最佳容量；另一个参数可能只轻微影响价值，却让最佳容量明显移动。对实际规划而言，后者往往更值得关注，因为它会改变执行方案。

## 常见错误

### 只求导，不检查二阶形状

导数为零可能是最大、最小或更复杂的驻点。

### 把连续数学最优直接当现实执行量

车辆、班次、员工、设备常常具有离散或标准规格。

### 忽略量纲

如果 x 的单位从“单件”改成“百件”，函数系数也必须同步转换。

### 认为固定成本不重要

固定成本可能不改变内部最优位置，但会改变方案是否值得采用。

### 只报告 x*，不解释曲线平缓程度

管理者真正关心的往往是偏离最优的代价，而不只是最优点本身。

### 看到 Solver 给出一个数就当成 global optimum

非凸函数可能存在多个局部最优；需要结合函数结构、不同起点与邻域检查判断。

### 把连续最优简单四舍五入成整数

离散可执行值应重新计算目标；如果存在固定费用或逻辑切换，则需要重新建成整数模型。

## 核心判断

无约束优化的核心不是“找到导数为零的点”，而是理解：

> **目标函数怎样随决策变化、边际改善在哪里消失、函数形状能否保证全局最优，以及数学最优附近是否存在现实可执行的近最优选择。**

下一篇加入显式约束：当材料、人工、容量或需求边界开始限制决策时，最优点将从函数自身的峰值转向可行域边界与角点。

## 为什么一个解释变量往往不够

简单回归适合先看两个变量之间的关系，但真实业务很少只受一个因素影响。

配送时间可能同时受距离、订单件数、优先级和交通状况影响；客户消费金额可能同时和收入、客户类型、活跃时长有关。只把其中一个变量放进模型，其他因素的影响就可能混到它的系数里。

多元线性回归把多个解释变量放进同一个模型：

\[
Y_i=\beta_0+\beta_1X_{1i}+\beta_2X_{2i}+\cdots+\beta_pX_{pi}+\varepsilon_i
\]

公式看起来只是多了几项，但系数的含义已经发生了重要变化。

## “控制其他变量”到底是什么意思

假设配送时间模型是：

\[
Time=\beta_0+\beta_1Distance+\beta_2Items+\beta_3Priority+\varepsilon
\]

\(\beta_1\) 不再是距离和时间的简单相关关系，而是：在订单件数和优先级相同的情况下，距离每增加 1 个单位，平均配送时间怎样变化。

这就是多元回归常说的“保持其他变量不变”。

它并不意味着现实中真的能把所有其他因素锁死，只是模型在统计上把它们同时纳入，从而比较更接近同等条件下的差异。

## 简单回归和多元回归的系数为什么会不同

如果距离和订单件数本身有关，而订单件数又会影响配送时间，那么只回归 `Time ~ Distance` 时，距离的系数可能混入一部分订单规模的影响。

加入 `Items` 以后，距离系数会变成控制订单件数后的关系，所以数值发生变化并不奇怪。

这也是为什么不能拿简单回归和多元回归中的同名系数直接说“模型不稳定”。先看模型里控制了哪些变量。不同模型回答的本来就可能是不同问题。

一个很实用的阅读习惯是：每次解释某个系数，都顺手把“在模型中的其他变量保持不变时”补在脑子里。

## 整体 F 检验先看模型有没有共同解释力

多元回归里，每个系数都有自己的 t 检验，但还有一个整体问题：这些解释变量放在一起，是否比只有截距的模型提供了更多信息？

经典整体 F 检验写成：

\[
H_0:\beta_1=\beta_2=\cdots=\beta_p=0
\]

如果拒绝这个原假设，说明至少有一个解释变量对 Y 的线性解释有贡献。

需要注意，整体 F 显著并不表示每个变量都显著，也不表示模型一定适合预测。它只是说明这一组变量整体上并非毫无信息。

R 的 `summary()` 会给出 F-statistic：

```r
model <- lm(time ~ distance + items + priority, data = delivery_df)
summary(model)
```

如果需要比较嵌套模型，也可以使用：

```r
anova(model_small, model_large)
```

## 部分效应比“单变量相关”更接近系数含义

多元回归里，\(\beta_j\) 关注的是 Xj 在其他变量已经进入模型以后，还能解释多少 Y 的变化。

可以把它理解为先从 Xj 中拿掉其他解释变量能够解释的部分，再看剩下的 Xj 是否仍然和 Y 有关系。

这正是 partial regression 的直觉。

因此，某个变量和 Y 的简单相关很高，不代表它在多元模型里一定重要。反过来，一个简单相关不强的变量，在控制混杂因素以后也可能变得更清楚。

## 变量彼此相关并不是问题本身

业务变量之间存在相关非常正常。距离更长的订单可能件数也更多，客户收入和消费水平可能相关，多个市场指标也可能一起变化。

真正麻烦的是解释变量之间相关得太强，以至于模型很难区分“到底是谁在解释 Y”。这就是多重共线性。

假设两个变量几乎总是同步变化。模型可以很好地预测它们的组合效果，却很难稳定分配给各自一个单独系数。结果常见为：

- 系数标准误变大；
- 单个 t 检验不稳定；
- 样本稍微变化，系数就明显变化；
- 系数符号甚至可能翻转；
- 整体预测仍然可以不错。

所以“有共线性”和“模型完全不能用”并不是同一句话。

## 先看相关矩阵，但不要停在那里

相关矩阵能快速发现两两高度相关的变量：

```r
cor(df[c("distance", "items", "weight")])
```

它很有用，但只能看到两两关系。有时某个变量并不和任何单个变量极度相关，却能被其他几个变量的组合很好解释，这种情况单看相关矩阵就容易漏掉。

因此，相关矩阵适合作为第一眼检查，而不是共线性诊断的终点。

## VIF 衡量一个变量被其他变量解释了多少

Variance Inflation Factor，简称 VIF，是最常见的共线性指标之一。

对第 j 个解释变量：

\[
VIF_j=\frac{1}{1-R_j^2}
\]

其中 \(R_j^2\) 来自把 \(X_j\) 当作结果，用其他解释变量去回归它。

直觉很简单：如果其他变量几乎能把 Xj 预测出来，那么 \(R_j^2\) 很高，VIF 就会变大。也就是说，Xj 在模型中缺少独立变化，系数自然更难估准。

常见的 5 或 10 只是经验阈值，不应该当成数学红线。样本量、研究目标和变量含义都会影响判断。

## 共线性主要伤害解释，不一定伤害预测

这是多元回归里非常重要的区别。

假设两个变量高度相关。它们的单独系数可能很不稳定，但两者组合出来的拟合值仍然可能很稳定。因此，如果目标是解释“每个变量各自贡献多少”，共线性会很麻烦；如果目标主要是预测，而且未来数据保持类似的相关结构，影响可能没有想象中大。

不过预测也并非完全安全。如果未来变量关系发生变化，依赖共线性结构的模型也可能变得脆弱。

所以是否处理共线性，应该先看模型是为了因果解释、业务解释，还是预测。

## 不要为了降低 VIF 随意删变量

看到 VIF 高，最简单的动作是删掉一个变量，但这不一定合理。

如果变量是重要控制因素，删除它反而可能带来遗漏变量问题。更好的处理顺序是：

1. 检查变量是否其实测量同一个概念；
2. 看是否存在重复或高度派生的字段；
3. 回到业务目的，判断哪些变量必须保留；
4. 比较删减前后的系数、预测和解释是否真的更好；
5. 若目标偏预测，可考虑 Ridge 等正则化方法。

共线性是模型结构问题，不是看到一个大数字就自动删列的指令。

## 系数稳定性要用情景比较来判断

除了 VIF，还可以比较不同模型或不同样本下的系数。

例如：

```r
m1 <- lm(y ~ x1 + x2 + x3, data = df)
m2 <- lm(y ~ x1 + x2, data = df)
coef(m1)
coef(m2)
```

如果只删掉一个变量，其他系数就剧烈变化，需要进一步查清楚原因。

也可以用重抽样或交叉验证观察估计是否稳定。真正值得担心的不是“系数有一点变化”，而是结论对很小的数据或设定变化异常敏感。

## 多元回归最容易犯的解释错误

### 把条件关系说成简单相关

多元模型里的系数是在控制其他变量以后得到的，不能再按单变量相关那样解释。

### 把显著性当成业务重要性

p 值小只说明当前样本对“系数是否为零”有较强证据，不说明影响一定大。

### 看到相关变量就认为模型无效

相关是常态。关键是它是否已经严重影响系数精度和稳定性。

### 为了让 VIF 好看随意删控制变量

如果被删掉的是重要混杂因素，模型解释反而可能更差。

## 一套更稳妥的阅读顺序

面对多元回归结果，可以先按这个顺序看：

1. 模型里有哪些变量，它们为什么需要一起出现；
2. 整体 F 检验是否表明这组变量共同提供了信息；
3. 逐个解释系数时明确“控制了哪些变量”；
4. 看标准误和置信区间，而不是只看 p 值；
5. 用相关矩阵和 VIF 检查变量之间是否过度重叠；
6. 比较不同设定下系数是否稳定；
7. 最后根据解释或预测目标决定是否简化模型。

多元线性回归真正有价值的地方，不是把更多变量塞进公式，而是让“在其他条件相近时，这个变量和结果是什么关系”变得更清楚。

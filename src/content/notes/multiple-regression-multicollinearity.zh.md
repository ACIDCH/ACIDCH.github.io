## 多元回归的核心是“保持其他变量不变”

多元线性回归把多个解释变量放进同一个条件均值模型：

\[
Y_i=\beta_0+\beta_1X_{1i}+\beta_2X_{2i}+\cdots+\beta_pX_{pi}+\varepsilon_i
\]

与简单回归相比，最大的解释变化不是变量数量，而是系数成为**条件效应**。\(\beta_1\) 表示在其他解释变量保持不变时，\(X_1\) 每变化一个单位，Y 的条件均值平均变化多少。

假设配送时长模型包含距离、订单件数和优先级：

\[
DeliveryHours=\beta_0+\beta_1Distance+\beta_2Items+\beta_3Priority+\varepsilon
\]

那么距离系数不是“所有远距离订单平均更慢多少”，而是在订单件数和优先级相同的比较条件下，距离增加对应的时长变化。

这使多元回归具有控制混杂结构的能力，但“控制”不自动等于因果识别。遗漏变量、反向因果、测量误差和选择机制依然可能存在。

## 为什么简单回归与多元回归系数会不同

如果距离和订单件数本身相关，而订单件数又影响配送时长，那么简单模型：

\[
Y=\alpha_0+\alpha_1Distance+u
\]

中的距离系数可能同时吸收一部分订单件数信息。加入 `Items` 后，距离系数会转向更接近“在相同订单规模下”的条件关系。

系数变化不是模型“出了问题”，而是估计对象改变了。任何系数解释都必须同时说明模型中控制了哪些变量。

## 整体 F 检验与单个 t 检验回答不同问题

单个系数 t 检验通常检验：

\[
H_0:\beta_j=0
\]

整体 F 检验则常检验：

\[
H_0:\beta_1=\beta_2=\cdots=\beta_p=0
\]

也就是所有解释变量相对于只有截距的模型是否整体提供额外解释力。

还可以进行部分 F 检验，比较两个 nested models，例如：

- reduced：距离 + 件数
- full：距离 + 件数 + 优先级 + 距离×优先级

这类比较判断新增的一组项是否共同改善拟合，而不是逐个查看多个 p 值。

## 多重共线性是什么

当一个解释变量可以被其他解释变量高度预测时，模型难以区分各变量独立贡献。极端情况下，如果存在完全线性关系，例如：

\[
X_3=X_1+X_2
\]

设计矩阵不满秩，某些系数无法唯一估计。

更常见的是“近似共线性”：变量高度相关但不是完全相同。OLS 仍可以计算，却可能出现：

- 系数标准误显著增大；
- 估计系数对样本微小变化敏感；
- 单个变量 p 值不显著，但整体模型显著；
- 系数符号与简单相关方向相反；
- 预测可能仍较稳定，但解释性变差。

## 相关矩阵只是第一层筛查

Pearson 相关矩阵可以快速发现两两高度相关的数值变量，但它无法捕捉“一个变量由多个其他变量共同解释”的高维共线结构。

例如，X1 与 X2、X3 的两两相关都只有中等水平，但 X1 可能几乎等于 X2 与 X3 的某个组合。因此，仅凭“没有相关系数超过 0.8”不能宣布不存在共线性。

## VIF把共线性写成一个可解释数字

对第 j 个解释变量，用其他解释变量回归它：

\[
X_j=\gamma_0+\sum_{k\neq j}\gamma_kX_k+v
\]

得到 \(R_j^2\)，然后：

\[
VIF_j=\frac{1}{1-R_j^2}
\]

如果其他变量几乎不能解释 Xj，\(R_j^2\) 接近 0，VIF 接近 1；如果 Xj 被其他变量高度解释，VIF 会快速上升。

VIF 没有绝对统一的“合格线”。2、5 或 10 都只能当经验提醒。更重要的是结合研究目标：如果核心任务是解释单个系数，系数不稳定很严重；如果任务主要是预测，而且验证集表现稳定，共线性可能不是首要风险。

## 共线性不是“变量相关就删一个”

处理方式取决于变量为什么相关。

### 语义重复

例如 `total_orders` 与 `monthly_orders * months_active` 几乎是同一信息，应优先重新定义特征而不是机械保留两者。

### 同一业务概念的多个代理变量

例如客户规模可以同时由收入、员工数和订单量表示。此时可以选最稳定、最可解释的一项，或者构建综合指标。

### 理论上都必须保留

如果变量代表不同机制，即使相关，也可能不应删除。应接受标准误变大，或者用更大样本、正则化、主成分方法等改善稳定性。

### 多项式与交互导致的结构性共线

X 与 X² 经常高度相关。中心化 X 可以降低数值相关性并改善解释，但不会改变模型拟合本质。

## Partial regression帮助看“控制后”的关系

要观察 X1 在控制 X2、X3 后与 Y 的关系，可以先：

1. 用 X2、X3 回归 Y，得到 Y 的残差；
2. 用 X2、X3 回归 X1，得到 X1 的残差；
3. 把两组残差作图。

该图展示的是双方都剔除其他解释变量线性部分后剩余的关系，因此更接近多元回归系数的几何含义。

在 R 中 `car::crPlots()` 或 added-variable plots 可以帮助做类似诊断，但图形解释仍需要回到模型定义。

## 对数结果变量如何解释

多元回归常对价格、成本、时长等右偏变量取对数：

\[
\log(Y)=\beta_0+\beta_1X_1+\cdots+\varepsilon
\]

如果 X1 增加 1，Y 的近似百分比变化常写为 \(100\beta_1\%\)；更精确的变化为：

\[
100(\exp(\beta_1)-1)\%
\]

当解释变量本身也取 log 时，系数可能变成 elasticity。不同变换对应不同业务问题，不能只为了提高 R² 而转换。

## R 中的多元回归检查

```r
model <- lm(log(cost) ~ distance_km + order_size + priority, data = delivery)
summary(model)
anova(model)

cor(delivery[c("distance_km", "order_size")])
car::vif(model)
```

建议同时保留：变量字典、模型公式、样本量、缺失值处理规则和基准组。否则即使同一段代码可运行，也可能因为数据口径变化而得到不可比结果。

## 系数稳定性比单次显著性更有价值

对解释性模型，可以通过若干替代规格检查关键系数：

- 加入或移除非核心控制变量；
- 改变明显异常记录处理方式；
- 使用合理变量变换；
- 按时间或业务分组重复估计。

如果某个系数方向和量级在轻微规格变化下剧烈跳动，说明结论依赖模型选择。此时只报告一个最终 p 值会隐藏不确定性。

## 常见错误

- 把多元回归系数解释成无条件平均关系。
- 看到变量之间相关就自动删除其中一个。
- 只检查 pairwise correlation，不看 VIF 或模型结构。
- 把 VIF>5 当成必须删除变量的硬规则。
- 忽略类别变量 reference level 与交互。
- 对 log(Y) 模型直接按原始单位解释系数。
- 单次模型显著就不再检查规格稳定性。

## 诊断不是“看四张默认图”

回归诊断的目标不是完成一个固定绘图清单，而是回答：**模型的结构是否与数据生成过程足够一致，以至于系数、区间和预测仍然可信？**

普通线性回归通常依赖几类核心条件：条件均值关系的函数形式大致正确；误差的条件均值接近 0；误差方差在解释变量范围内没有严重系统变化；观察值之间的独立性满足分析设计；在需要 t/F 推断时，误差分布没有严重偏离使小样本推断失真。

这些条件不是通过一个数字同时验证，而是由不同图形和统计量分别提供证据。

## 残差到底是什么

残差定义为：

\[
e_i=y_i-\hat y_i
\]

它是样本中“实际结果”和“模型拟合结果”的差。残差不是总体误差 \(\varepsilon_i\) 本身，而是对误差的可观察近似。

把 fitted values 放在横轴、residuals 放在纵轴，是最重要的回归诊断图之一。理想情形通常表现为点云随机围绕 0 分布，没有持续曲率，也没有明显漏斗形。

## 残差图中的四种典型结构

### 随机云状

如果残差在 0 两侧无明显结构，且离散程度大致稳定，说明线性函数形式与方差假设没有出现明显反证。这里的目标不是“完美随机”，真实数据几乎不会形成教科书式图形。

### 漏斗形

当 fitted values 增大时，残差带逐渐变宽或变窄，常见解释是异方差：

\[
Var(\varepsilon_i\mid X_i)\neq \sigma^2
\]

异方差不一定让 OLS 系数本身失去无偏性，但会影响传统标准误和区间推断。业务上也可能意味着高价值订单、高负荷客户或大规模工单本来就具有更高的不确定性。

### 弯曲结构

残差先正、后负、再正，或者形成持续弧线，常提示线性函数形式不足。此时直接增加更多线性变量未必解决问题，更合理的方向可能包括变量变换、多项式项、交互项、分段关系或重新定义预测对象。

### 单点远离主体

单个大残差可能是 response outlier，但是否会显著改变回归线，还取决于它在 X 空间的位置。一个 Y 很异常但 X 位于样本中心的点，影响力可能低于一个残差不算极端但 X 非常远的高杠杆点。

## Scale–Location 图检查方差结构

Scale–Location 图常将拟合值与标准化残差绝对值的平方根放在一起。与原始 residual plot 相比，它把正负残差都映射到非负尺度，更容易观察残差振幅是否随着 fitted values 系统增大。

如果图中平滑趋势明显向上，不应只写“存在异方差”就结束。还要继续追问：这种方差变化来自单位尺度、分组结构、遗漏变量，还是结果变量本身适合使用对数等变换？

例如交易金额、处理时长和收入类变量经常随均值增大而增大波动，对数变换有时能够同时改善线性和方差稳定性：

\[
\log(Y)=\beta_0+\beta_1X+\varepsilon
\]

但变换后系数解释也会改变，不能只为了“图变好看”而转换。

## QQ 图检查什么

正态 QQ 图比较标准化残差的经验分位数与理论正态分位数。若点大致落在参考直线附近，说明残差分布与正态形状相容；明显 S 形、尾部偏离或单侧翘起则提示重尾、偏态或异常点。

需要区分两个问题：**线性回归的点预测是否可用**，以及**经典小样本 t/F 推断是否可靠**。在样本量较大、模型结构合理时，轻微非正态不一定是最严重的问题；明显非线性、数据依赖或强影响点通常更值得优先处理。

因此，QQ 图不应机械地变成“必须通过正态性测试”的门槛。

## 标准化残差帮助比较不同观察值

原始残差的尺度会受到不同 leverage 的影响。标准化或学生化残差把残差除以其估计标准差，使不同观察值更容易比较。

常见经验规则会关注 \(|r_i|>2\) 或更大的记录，但它们只是筛查线索，不是删除规则。样本越大，出现几个绝对值超过 2 的残差本来就可能是正常事件。

## 独立性往往不是靠残差图解决

如果数据是时间序列、同一客户的重复记录、同一门店的多日观察或同一设备的多次测量，误差很可能存在相关性。此时“散点看起来随机”并不能保证独立。

应先回到数据生成过程：

- 一行是否真的是独立业务单位？
- 同一个实体是否重复出现？
- 是否存在时间顺序和季节性？
- 是否有空间或组织层级聚类？

如果设计本身存在依赖，可能需要时间序列、面板、混合效应或 cluster-robust 等更合适的方法，而不是继续修饰普通 OLS 残差图。

## 诊断优先级：先处理结构，再讨论“像不像正态”

多个诊断信号同时出现时，处理顺序很重要。一个常见但低效的流程，是先盯着 QQ 图尾部的小幅偏离，再去做各种正态性检验；与此同时，Residuals vs Fitted 中已经存在清楚的曲率或漏斗形。这会把注意力放在次要问题上。

更稳健的优先级通常是：先确认观察单位和数据生成过程，再检查明显函数形式错误与依赖结构，然后检查方差、强影响记录，最后才讨论残差分布对推断的影响。原因是函数形式错误会改变条件均值本身，而轻微非正态更多影响有限样本下的推断精度。若均值结构已经写错，即使残差通过某个正态性检验，也不能使模型变得正确。

诊断还应与任务类型配对。解释任务更关心系数与区间是否稳健；预测任务更关心样本外误差、极端区域和校准。相同的异方差信号，在“解释平均边际效应”和“预测下一条高价值订单”中可能具有不同严重程度。

## R 中的基础诊断流程

```r
model <- lm(delivery_hours ~ distance_km, data = delivery)

par(mfrow = c(2, 2))
plot(model)
par(mfrow = c(1, 1))

residuals(model)
rstandard(model)
hatvalues(model)
cooks.distance(model)
```

默认四图提供的是起点。正式分析最好把每一张图连接到明确问题：Residuals vs Fitted 检查函数形式与方差；Normal Q-Q 检查尾部和分布形状；Scale-Location 更突出方差变化；Residuals vs Leverage 把残差和杠杆结合起来看影响。

## 发现问题后该怎么修

诊断的价值在于决定下一步，而不是给模型贴标签。

| 发现 | 优先检查 | 可能动作 |
| --- | --- | --- |
| 残差呈曲线 | 函数形式 | 变量变换、多项式、交互、分段 |
| 漏斗形 | 条件方差 | 变换、稳健标准误、重新定义误差模型 |
| QQ 尾部偏离 | 极端值/重尾 | 查数据来源、稳健分析、区间方法 |
| 单个高残差 | 数据质量/稀有情景 | 核验记录并做敏感性分析 |
| 高 leverage | X 空间覆盖 | 检查外推与样本代表性 |
| 时间结构 | 独立性 | 引入时间、层级或相关误差结构 |

修正后必须重新诊断。模型变换不是“一次性治疗”，每次改变函数形式都会产生新的残差结构。

## 修正前后必须形成同一条证据链

诊断动作只有在能够比较“修正前”和“修正后”时才真正可审计。例如发现漏斗形后使用 log(Y)，不能只展示新的残差图并宣布问题消失；还应对比关键系数方向、区间宽度、样本外误差与原始业务尺度上的预测解释。

一个实用的记录框架包括：原模型信号、假设原因、修正方法、修正后诊断、核心结论是否变化、代价是什么。若变换显著改善残差，却让业务解释复杂很多，需要明确说明这种折中。若稳健标准误只改变区间而不改变点估计，则应区分“估计关系未变”和“推断不确定性被重新评估”。

同样，若加入二次项后残差曲率消失，但交叉验证误差没有改善，说明该结构可能更有解释价值而非预测价值。诊断不是把所有图调成理想形状，而是使模型用途、统计条件和业务解释彼此一致。

## 诊断与业务语境必须一起读

假设高价值客户的服务时间波动明显更大。统计上它表现为异方差；业务上却可能说明高价值客户的需求类型更加多样。如果只用一个技术动作让标准误变稳健，却不分析这种结构本身，就会丢掉有价值的信息。

同样，一个异常点可能不是数据错误，而是一次重大故障或极端供应中断。此时它既是模型诊断问题，也是风险管理问题。

## 一条可审计的诊断记录

正式回归分析应留下至少四类信息：观察到的图形信号、可能原因、采取的处理动作、处理前后结论是否变化。

例如：

> Residuals vs Fitted 显示高 fitted values 处方差增大；检查发现结果变量为处理时长且右偏明显；使用 log 结果变量重新估计后方差结构改善；关键解释变量方向保持一致，但原始尺度预测需反变换并报告区间。

这样的记录比一句“assumptions satisfied”更容易复核。

## 常见诊断误区

- 默认四张图全部生成后就宣布模型有效。
- 把 QQ 图轻微偏离当成比严重非线性更大的问题。
- 看到 |standardized residual|>2 就自动删除。
- 只处理图形，不检查数据生成过程。
- 变换变量后沿用原来的系数解释。
- 使用稳健标准误后就忽略异方差本身的业务含义。

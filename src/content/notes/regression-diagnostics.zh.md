## 模型跑出来以后，真正的检查才开始

一份回归输出可以很整齐：系数有数字，R² 也不低，p 值甚至都很好看。但这些结果成立的前提，是模型对数据结构的描述没有明显偏离。

回归诊断做的就是这件事。它不负责重新解释业务，而是检查模型留下来的“残差”有没有规律。如果残差还带着清楚的曲线、漏斗、分组或极端点，说明模型漏掉了某些结构。

线性回归里常见的检查包括：

- 条件均值的函数形式是否大致正确；
- 残差方差是否在不同拟合水平下差不多；
- 是否存在特别极端或高影响的观察；
- 在需要小样本推断时，误差分布是否偏离得太严重；
- 数据的独立性假设是否与采样方式相符。

这些问题不会靠一张图全部回答，所以诊断图应该按“它在检查什么”来读，而不是把四张默认图当作任务清单。

## 残差是模型没解释掉的部分

第 i 条记录的残差是：

\[
e_i=y_i-\hat y_i
\]

实际值高于预测值时，残差为正；实际值低于预测值时，残差为负。

需要注意，残差不是总体里的真实误差 \(\varepsilon_i\)，只是根据样本得到的可观察近似。不过它已经足够告诉很多问题：模型在哪些位置经常低估，哪些位置经常高估，误差大小是否随着拟合值变化。

最常见的图是 fitted values 对 residuals：

```r
plot(fitted(model), residuals(model))
abline(h = 0, lty = 2)
```

理想状态不是“所有点都靠近 0”，而是点云在 0 上下比较随机，没有清楚的系统形状。

## 残差图出现弯曲，通常说明直线太简单

如果残差从左到右出现明显的 U 形或倒 U 形，常见原因是原来的线性形式没有抓住数据的曲率。

例如真实关系更接近：

\[
Y=\beta_0+\beta_1X+\beta_2X^2+\varepsilon
\]

却只拟合了：

\[
Y=\beta_0+\beta_1X+\varepsilon
\]

这时模型往往会在某些区间持续高估，在另一些区间持续低估。残差图于是留下有方向的弯曲。

处理方法不是看到曲线就机械加平方项。先回到变量本身：业务上是否有饱和、阈值、规模效应或其他非线性理由。如果有，再比较更合适的函数形式。

## 漏斗形通常指向异方差

如果 fitted values 越大，残差的上下波动也越大，图形看起来像张开的漏斗，这通常提示 **heteroscedasticity（异方差）**。

异方差并不一定让 OLS 系数点估计立刻失效，但会影响标准误和推断的可靠性。最直接的问题是：模型假设“误差波动差不多”，数据却显示高水平区域的误差明显更大。

在金额、规模、销量这类变量中，这种情况并不少见。绝对误差随着业务规模增大，有时比“所有记录都保持相同波动”更符合实际。

处理方式要看问题来源，可以考虑变量变换、重新指定均值结构、稳健标准误，或者换用更合适的模型。重要的是先确认现象，而不是看见漏斗后立刻套某一种修复。

## Scale–Location 图把方差问题看得更清楚

Scale–Location 图通常把：

\[
\sqrt{|standardized\ residual|}
\]

画在纵轴，把 fitted values 放在横轴。

它的作用和残差图有重叠，但更强调残差大小而不是正负方向。如果图上的平均趋势明显向上，往往表示拟合值越大，残差规模也越大。

在 R 的基础诊断图中可以直接看到：

```r
plot(model, which = 3)
```

这张图不需要追求“完全水平”。真实数据很少这么理想。更值得关注的是有没有清楚、持续、足以影响推断的趋势。

## QQ plot 看的是尾部和分布形状

QQ plot 常被误读成“点不在直线上，所以模型不能用”。实际要更谨慎。

标准正态 QQ 图把样本残差分位数与理论正态分位数比较：

```r
qqnorm(rstandard(model))
qqline(rstandard(model))
```

如果中间大部分点接近直线，但两端略有偏离，在大样本中未必是严重问题。真正值得留意的是系统性的 S 形、明显长尾，或者少数点远离整体。

正态性主要影响小样本下基于 t/F 分布的经典推断，并不是 OLS 能不能算出一条线的前提。把“误差不完全正态”和“模型完全无效”画等号，会把诊断问题夸大。

## 单个极端点需要和整体结构分开看

残差很大的点不一定最有影响力。一个观察是否会明显改变模型，还取决于它在解释变量空间中的位置。

因此，诊断时最好把三个概念分开：

```text
大残差
→ Y 方向上偏离模型

High leverage
→ X 组合位于数据边缘

High influence
→ 删除该点后模型结果明显改变
```

Cook’s distance 会把残差和 leverage 的信息结合起来，适合用来发现可能改变整体拟合的记录。后面的“异常点与影响点”会专门展开这一部分。

## 图上有问题，不等于应该删数据

看到某个点特别远，第一反应不应该是删除。

先问几件事：

1. 这条记录是不是录入错误？
2. 单位、时间范围或字段含义有没有弄错？
3. 它是不是一个真实但少见的业务情况？
4. 模型是不是漏掉了某个变量或非线性结构？
5. 保留和去掉这条记录，结论会改变多少？

只有确认数据本身不可信时，删除才是清洗问题。真实但极端的业务记录通常更适合保留，并用敏感性分析说明它对模型有多大影响。

## 诊断要和业务过程放在一起

一些图形问题来自模型形式，一些问题来自数据产生方式。

例如时间序列里的残差连续同号，可能是自相关；同一个客户被重复观测，可能导致记录并不独立；不同门店的波动水平完全不同，可能意味着分组结构没有进入模型。

这类问题只盯着默认回归图往往不够。建模时需要知道一行数据是怎么来的、是否有时间顺序、是否属于某个组，以及采样过程有没有天然依赖。

统计诊断真正有用的地方，就是把这些数据生成信息和图形证据接起来。

## 一套实用的诊断顺序

模型拟合后，可以按下面的顺序检查：

1. **Residuals vs Fitted**：先看是否有曲率、分组和明显漏斗；
2. **Scale–Location**：确认残差规模是否随拟合值变化；
3. **QQ plot**：检查尾部和分布形状是否异常；
4. **Leverage / Cook’s distance**：找可能改变整体结果的观察；
5. 回到原始数据核对可疑记录；
6. 根据问题来源调整模型，再重新画诊断图。

最后一步很重要。修正模型之后，要看原来的结构有没有真的消失，而不是仅凭“换了一个更复杂的模型”就宣布问题解决。

## 小结

回归诊断的核心不是把四张图逐张描述，而是读出残差里还剩下什么结构：

- 弯曲通常提醒函数形式不够；
- 漏斗常常对应异方差；
- QQ plot 主要帮助判断分布尾部；
- 大残差、高 leverage 和高影响点不是同一个概念；
- 任何“删点”决定都应该先有数据和业务依据。

一个模型看起来拟合得不错，只是起点。残差没有明显留下可解释的规律，系数和预测才更值得信任。
